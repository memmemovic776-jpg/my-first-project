Требуется протокол HTTP/HTTPS или локальный сервер

Браузеры блокируют запись микрофона (ошибка Permission Denied), если HTML-файл открыт напрямую с диска или мобильного хранилища (content:// или file://).

Варианты решения:
  1. Запустите через VS Code Live Server или локальный HTTP-сервер (http://localhost:8080).
  2. На смартфоне используйте приложения вроде Simple HTTP Server для открытия файла.
  3. Либо загрузите записанный файл .mp3 / .wav напрямую во вкладке "Мой голос" без использования микрофона браузера.
